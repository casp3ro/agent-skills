# {{title}}

A structured, rule-based skill optimized for AI agents and readable by humans.

## Structure

- `SKILL.md` - Entry point loaded by agents (frontmatter, priorities, generated quick reference)
- `rules/` - One file per rule; `_sections.md` defines sections, `_template.md` is the rule template
- `metadata.json` - Title, version, organization, abstract, references
- `AGENTS.md` - Compiled guide with every rule expanded (generated by `npm run build`)
- `../../evals/{{name}}/` - Task evals, trigger evals, generated test cases

## Creating a New Rule

Use `/new-rule {{name}} <prefix> "<title>"` in Cursor or Claude Code, or copy `rules/_template.md` to `rules/<prefix>-<description>.md`, then run `npm run build && npm run validate`.

## Impact Levels

- `CRITICAL` - Prevents crashes, security issues, or data loss
- `HIGH` - Significant correctness or maintainability gains
- `MEDIUM-HIGH` - Important for production quality
- `MEDIUM` - Clear design and consistency improvements
- `LOW-MEDIUM` - Operational and stylistic improvements
- `LOW` - Incremental refinements
