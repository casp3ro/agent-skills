# Research briefs

One file per skill or skill idea: `docs/research/<name>.md`, written by `/research-skill` (the `skill-researcher` subagent).

Each brief records prior art on skills.sh and GitHub (with licenses), current facts with primary sources, common agent mistakes the skill must prevent, baseline eval failures, and the build / extend / skip decision. Reviewers use it to verify the skill's claims, so keep it current when a skill changes.

These files are not published with the skills.
